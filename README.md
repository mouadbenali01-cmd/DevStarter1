# DevStarter

A lightweight personal workspace for beginner developers to track learning tasks, technologies, and project ideas.

## Features

- Add, complete, and delete learning tasks
- Filter tasks by all, active, or completed
- View an automatically updated task completion progress bar
- Keep a list of technologies you're studying
- Save and remove future project ideas
- View simple progress statistics
- Automatically save data in the browser with `localStorage`
- Responsive layout for desktop and mobile

## Getting started

No build tools or dependencies are required.

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Start adding your learning tasks, topics, and ideas.

## Built with

- HTML5
- CSS3
- Vanilla JavaScript
- Browser `localStorage`

## Data and privacy

Your entries are stored locally in your browser. This project does not send your data to a server.
